# Gradino Studio — content

Очередь публикаций для Instagram студии Gradino Studio (@gradino.studio; до смены handle — @gladiroon.studio) и робот, который их публикует.
Репозиторий пока называется `gladiroon-content`; план — переименовать в `gradino-content` (робот берёт имя репозитория из `GITHUB_REPOSITORY`, код менять не нужно).
Работает через официальный Instagram API with Instagram Login (graph.instagram.com) и GitHub Actions.

## Как это работает

1. Claude кладёт картинки в `media/<дата>/` и задание в `queue/<дата-время>-<тип>.json` — **только после «да» Исломбека**.
2. Робот запускается каждые 15 минут и при каждом push в `queue/`.
3. Созревшие задания (`publish_at` уже наступил) публикуются, файл переезжает в `published/` вместе с id и ссылкой на пост.
4. Ошибка → до 3 попыток, потом файл уходит в `failed/` с текстом ошибки. GitHub присылает письмо о неудачном запуске.

## Задание

```json
{
  "type": "carousel",
  "files": ["media/2026-11-15/01.jpg", "media/2026-11-15/02.jpg"],
  "caption": "Текст подписи #branding",
  "alt_text": "",
  "publish_at": "2026-11-15T09:00:00+01:00"
}
```

| type | files | Примечание |
|---|---|---|
| `image` | 1 JPEG | 4:5 … 1.91:1, до 8 MB |
| `carousel` | 2–10 JPEG/MP4 | все кадры обрезаются по пропорции первого |
| `story` | 1 JPEG или MP4 | 1080×1920; подписи и стикеров нет |
| `reel` | 1 MP4 | можно `"cover": "media/…/cover.jpg"` |

`publish_at` без часового пояса считается по Берлину. Пусто — публикуется сразу.

## Проверка без публикации

`python3 scripts/robot.py validate` — проверяет все задания: JPEG, размер, пропорции, длину подписи, хэштеги со смешанным алфавитом.

В GitHub: Actions → Publish to Instagram → Run workflow → `check` — проверяет токен, тип аккаунта и квоту.

## Секреты и переключатель

Settings → Secrets and variables → Actions:

| Имя | Где | Что |
|---|---|---|
| `IG_TOKEN` | Secrets | токен Instagram (60 дней, обновляется сам) |
| `IG_USER_ID` | Secrets | необязательно, робот узнаёт сам |
| `GH_PAT` | Secrets | fine-grained токен GitHub только на этот репозиторий, право *Secrets: Read and write* — нужен, чтобы сохранить обновлённый IG_TOKEN |
| `PUBLISHING_ENABLED` | Variables | `true` — робот публикует. Любое другое значение — пауза |

Секреты видит только GitHub. В коде и логах их нет.

## Что API не умеет

Хайлайты, закрепление, стикеры (опрос, вопрос, ссылка), музыка из библиотеки, смена категории и bio — это только в приложении.

## Важно

- Репозиторий публичный: Instagram скачивает файлы по открытой ссылке. Всё в `media/` и `queue/` видно до публикации.
- GitHub отключает расписание в публичном репозитории, если 60 дней не было коммитов. Тогда: Actions → включить снова.
- Токен обновляется 1-го и 15-го числа. Если обновление не прошло 60 дней подряд, токен умрёт — нужно сгенерировать новый в Meta.
